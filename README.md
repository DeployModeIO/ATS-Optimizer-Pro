🚀 ATS Optimizer Pro

Beat the ATS filter frictionlessly. 

ATS Optimizer Pro is a 100% open-source, privacy-first web tool designed to help job seekers analyze, optimize, and generate ATS-friendly resumes. Applicant Tracking Systems (ATS) reject up to 75% of resumes before a human ever sees them. This tool analyzes your CV against 40+ criteria, scores it, and can automatically repair common issues with a single click.

100% Offline · No Servers · No Tracking · Made with love for the community by Luis.
✨ Features
🔍 Deep ATS Analysis

    6-Dimension Scoring: Evaluates Format, Structure, Keywords, Quantified Achievements, Action Verbs, and Length.
    40+ Criteria Checks: Detects missing sections, lack of metrics, clichés, weak verbs, and missing contact info.
    Keyword Density & Match: Identifies technical keywords in your CV and calculates a match percentage against a pasted job description.
    Visual Radar Chart: Vanilla JS HTML5 Canvas chart showing your CV's performance vs. the ATS optimal baseline.

⚡ 1-Click Auto-Repair

    Fix Everything Button: Automatically applies all possible fixes to your resume text.
    Smart Replacements: Replaces clichés ("responsible for") with strong action verbs ("led the management of").
    Auto-Quantification: Injects metrics placeholders into bullet points lacking numbers.
    Missing Data Injection: Adds placeholders for missing emails, phone numbers, LinkedIn profiles, and missing sections (Summary, Education, Skills).
    Diff Modal: Shows a before-and-after comparison of all applied changes and the score improvement.

📝 Professional CV Generator

    Side-by-Side Editor: A dedicated view to build your resume section by section.
    Real-Time Preview: See your professional, formatted CV update instantly as you type.
    Print to PDF: One-click printing optimized for saving your generated CV as a clean PDF file.

🌍 Multilingual Support

    Available in English, Spanish, French, Chinese, and Arabic.
    Full Right-to-Left (RTL) layout support for Arabic.
    The analysis engine recognizes action verbs and clichés in English, Spanish, and French.

🔒 Privacy First

    Zero Dependencies: No external CDNs, no Tailwind, no Chart.js, no Google Fonts. Everything is embedded.
    100% Local Processing: Your resume data never leaves your browser. No backend servers involved.

🛠️ Tech Stack

This project is built with pure web standards to ensure maximum compatibility, speed, and privacy.

    HTML5: Semantic structure and Canvas API for the radar chart.
    CSS3: Custom utility classes, CSS variables, animations, and responsive layout (no Tailwind).
    Vanilla JavaScript (ES6): All logic, DOM manipulation, analysis engine, and i18n system.

🚀 Getting Started

You don't need to install anything. 

    Download the index.html file.
    Double-click it to open it in your favorite web browser.
    Start optimizing your resume!

Alternatively, you can host it on GitHub Pages, Netlify, or any static hosting service for free.
📖 How to Use
Analyzing a CV

    Go to the Analizador (Analyzer) tab.
    Drag and drop a .txt file, or paste your resume text into the text area.
    Click Analyze to see your score and detailed findings.
    Click Repair All Automatically to fix issues, or click the individual Repair buttons on specific issues.
    Use the editor to make manual tweaks, then re-analyze.

Generating a CV

    Go to the Generador de CV (CV Generator) tab.
    Fill out the form fields (Name, Summary, Experience, Education, etc.).
    Watch the live preview update on the right.
    Click Descargar / Imprimir CV to save it as a PDF.
